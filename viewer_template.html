RingCentral Audit Trail

Automatic collection

Controls the Windows scheduled task that pulls new audit events for you.
Settings are read-only here. To change them, start this page with open_viewer.bat (it runs a small helper on your own computer only).
Keep the retrieval window a few days longer than the run interval so a late run never leaves a gap. RingCentral keeps at most 180 days.

Filter events

Everything is shown until you choose a filter. Combine as many as you like; each one narrows the table further. You can also type in the box under any column heading.
